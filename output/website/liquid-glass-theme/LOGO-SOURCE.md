# DearBody logo provenance

Both marks reference page 6 of the owner-supplied DEARBODY PLAYBOOK, Canva design `DAHL_W_c7U8`. The original editable/master logo files were not available; bundled marks are web recreations.

## Primary wordmark

`dearbody/assets/db-logo-burgundy.png` is the existing transparent RGBA 2172 × 724 recreation generated on 23 September 2026 from the primary DEAR BODY wordmark, preserving its raised PH and reference proportions. Its alpha mask renders exact burgundy or cream. Header and footer image pickers can replace it with supplied master artwork.

## Secondary mark

`dearbody/assets/db-logo-secondary.svg` is a vector recreation of the circular d/b monogram with PH, copied from the separate Bauhaus edition. It was traced from the low-resolution playbook screenshot, not an original master export. The supplied source screenshot remains `../brand-assets/canva-logo-page-6.png`.

The secondary snippet uses a CSS alpha mask, allowing the same artwork to appear in burgundy in the story section and cream in the footer. Theme settings → Brand artwork → Secondary circular DearBody mark accepts transparent replacement artwork. A solid-background image would mask as a rectangle, so use transparent artwork.
