## Applied direction

Three adult male friends share a spontaneous café moment, with all four men's fragrances together on the foreground table. Burgundy architecture, red/cream/golden-tan wardrobe and warm daylight apply the brand palette. The photograph emphasizes people, confidence and social connection; no single scent dominates.

The existing collection reference fixes the four bottle identities: Citrus Wish/golden yellow, Moonlight Velvet/colorless, Charme Envoûtant/amber orange and Sunset Cocktail/pale peach. All use the reference cylindrical glass, glossy black caps, silver collars and black labels. No canisters are needed in this lifestyle composition.

The image contains only existing product-label text. Headline and button remain live page elements. The preview uses cream headline/button styling against the burgundy image. Display type uses a heavy sans fallback closer to the actual visual playbook; licensed Cenzo Flare Bold and Helvetica Now Display files are still required for exact production typography. The text wordmark in the concept is a placeholder, not a replacement logo.
