# DearBody logo provenance

Both brand marks come from the owner's DEARBODY PLAYBOOK, Canva design DAHL_W_c7U8, page 6. Local reference: `output/website/brand-assets/canva-logo-page-6.png`. Official editable master artwork was unavailable.

- **Primary:** `dearbody/assets/db-logo-burgundy.png`, transparent RGBA 2172×724. This is the existing image-generated recreation of the wide DEAR BODY wordmark with raised PH. `snippets/db-logo.liquid` renders its alpha as an exact burgundy/cream CSS mask.
- **Secondary:** `dearbody/assets/db-logo-secondary.svg`, vector recreation of the circular intertwined d/b mark with PH, reused from the Bauhaus edition. `snippets/db-secondary-logo.liquid` renders it as an alpha mask in the story and footer.

These are website reproductions from the supplied playbook, not the official logo masters. Original master artwork can override them under **Theme settings → Brand artwork**. For the secondary mark, use an image with genuine transparency; its alpha becomes the current brand color. Primary/logo geometry is not redrawn using ordinary text.
