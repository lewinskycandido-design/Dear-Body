The quickest installation

Download the complete Shopify theme ZIP and upload it through Online Store → Themes → Import theme → Upload zip file. The editorial storefront, scent quiz and all DearBody assets are included.

Prefer to copy the code?

  1. Duplicate your existing draft and open Edit code.
  2. Create or replace every text file listed below at its exact folder and filename.
  3. Upload every raster asset listed below. Create assets/db-logo-secondary.svg as a text asset from the source selector.
  4. Connect the two collections and six quiz products in Customize, then add approved catalog details.
