# Fun, vibrant, warm and light — banner refresh

This full campaign refresh was generated with the built-in ImageGen tool for the user's requested mood: lively colour, candid personality, bright inviting light and believable Filipino settings. It covers every active banner and the homepage collection gateways in both visual directions.

The installed set contains 22 photographs:

- Homepage hero: Light and Dark, without product bottles.
- Women and Men homepage gateways: Light and Dark.
- Women, Men and Scent Finder page headers: Light and Dark.
- Our Story and footer banners: Light and Dark.
- Six individual product headers, each with exactly one adult Filipino person and the authentic fragrance.

Dark mode uses richer clothing and environmental colours while keeping the photography bright. Product images are grounded in the physical SKU references and canonical bottle geometry. The 72 locked product-gallery frames are outside this banner refresh and remain unchanged.

All text remains live in the supplied Cenzo Flare Bold and Helvetica Now Display Light fonts. Shared full-width banner sizing remains 600px on mobile and clamp(540px, 43vw, 650px) on desktop. Homepage category gateways retain their portrait layout.

## Files

- `originals/`: accepted native PNG outputs.
- `final-web/`: production JPEG exports, quality 91, with sRGB profile.
- `prompts/`: exact generation and revision prompts.
- `provenance/`: source paths, image reviews, previous manifests and installed-asset metadata.

JPEG exports preserve the native image dimensions without compositing, retouching, cropping or resampling. Browser cropping and contrast overlays are reviewed separately at desktop and phone widths. No Shopify changes are part of this update.

Current status: all 22 accepted photographs are installed and pass native-image and responsive integration review. The checksum file locks each accepted original and production JPEG. [Final QA](../qa/V8-BANNER-REFRESH-QA.md) records 84 banner cases, 1,608 checks, eight gateway cases and zero Theme Check findings.
