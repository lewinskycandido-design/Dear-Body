# Native Liquid preview

Run `npm install` inside this directory once, then `npm run preview`. Open [Light](http://127.0.0.1:4208/?visual_theme=light) or [Dark](http://127.0.0.1:4208/?visual_theme=dark).

This renders the **actual new theme files** with LiquidJS: `layout/theme.liquid`, JSON templates, header/footer section groups, all sections and snippets. It contains no substitute storefront HTML. Theme sources are authoritative; `public/` is generated.

Live storefront text and the local preview UI use the supplied **Helvetica Now Display Light** face at weight 300, with **Cenzo Flare Bold** display headings retained. The actual Display WOFF2 replaces the previous Text webfont in theme assets. The archived website-generated galleries used the earlier Cenzo/Text Regular typography; the current import preserves the owner's selected raster artwork without re-typesetting it. See [font source notes](../source-assets/fonts/README.md) for retained packages and optional font overrides. The prior website font-loading/layout verification is recorded in [Display font QA](../qa/DISPLAY-FONT-QA.md).

The current 72 gallery images are selected from the owner's `output/product-listing/GALLERY_REVIEW_2026-09-24.html`, limited to the six active website scents. Source folder `rtulle-and-satin` maps to live handle `rtulle-satin`. Source PNGs remain unchanged; `../reviewed-product-galleries/` records the source mapping and 1200px JPEG exports with 160px thumbnails. The existing frame order `01, 11, 12, 08, 09, 05, 06, 07, 02, 03, 04, 10`, autoplay, commerce behavior, 22 v9 banners and favicons are preserved. Current verification is recorded in [Review gallery import QA](../qa/REVIEW-GALLERY-IMPORT-QA.md).

The timestamped read-only Shopify product/collection snapshot provides real identifiers, public descriptions, product media, prices and availability. Availability and prices were refreshed from public Shopify product endpoints on **24 September 2026 at 09:58:18 UTC (17:58:18 Philippine time)**. All six fragrances were **available at ₱799** in that snapshot. Earlier sold-out fixtures were stale; native Shopify remains the authority for current availability. See [the collection availability snapshot](../qa/COLLECTION-AVAILABILITY-SNAPSHOT.json). Custom metafields are left empty because their live values are not publicly exposed. The PDP therefore exercises the actual theme's supplied-copy fallback, with live metafields taking precedence when present on Shopify.

The Finder renders owner-copy-based editorial profiles from the actual [native theme snippet](../theme/snippets/sj-finder-profile.liquid) for the six launch handles. These defaults are part of the upload theme, not preview-injected scoring fixtures. Non-empty native mood, scent-character, occasion and intensity values override each trait; explicit `scent_finder_enabled = false` opts out. “Intensity” is presented as scent feel, not a performance measure. Sold-out products remain discoverable with accurate stock labels unless “Available products only” is enabled.

Its five questions cover collection, mood, scent style, occasion and scent feel. Collection filters first; style/mood/occasion/feel weights are 5/3/1/1. It presents one highest-scoring match, or a clearly labelled discovery edit when all preferences are skipped. No eligible profiles produces an honest empty collection message. Current revision QA passed; see [Scent Finder QA](../qa/SCENT-FINDER-QA.md) for browser, native profile, scoring and interaction results.

The local server emulates predictive-search responses and section rendering. It rejects unavailable add-to-cart attempts; **the local preview cannot place orders** and sends no email, subscription or store mutation. It cannot certify inventory, payment, Shopify media players, recommendation ranking, the theme editor or external apps. Current [COD browser evidence](../qa/COD-ORDERS-BROWSER-QA.json) records the separately authorized store test and its cancellation/restock. Browser test fixtures are isolated in QA and never change product availability in this snapshot or upload theme. EasySell installation, its Free 60-orders/month plan and external settings are store configuration, not preview or ZIP contents.

The preview report lists rendered routes, one-H1 counts, duplicate IDs and missing local assets. `qa/` contains browser verification and screenshots. See [the asset audit](../ASSET-AUDIT.md) for original logo provenance, supplied brand fonts and Finder content provenance.

## Current homepage, price and gallery update

Three native homepage features use new generated photography: magnetic cap, collectible bottle-and-canister display, and free shipping on 2 or more items. The shipping canisters are individually bubble-wrapped. Live website text overlays the images on mobile; original photos and prompts are in `../campaign-v10-home-features/`.

Reduced-motion visitors browse manually. Current checks: [homepage update QA](../qa/HOMEPAGE-FEATURES-QA.md) and [gallery controls QA](../qa/GALLERY-CONTROLS-QA.md).
