# Superseded product still-life exploration

These still-life concepts were superseded when the user requested single-person Filipino lifestyle banners. They are not installed in the theme or shipped in the ZIP. The final source is `../campaign-v6-product-lifestyle/`.

Exploratory wide still-life photographs were created with the built-in `image_gen.imagegen` tool for the priority DearBody product pages. Each uses its approved bottle-and-canister reference plus the canonical bottle geometry reference. Scene direction comes from the owner's approved scent description and Canva-based warm brand palette.

The originals retain their native 1774 × 887 output, an exact 2:1 ratio. JPEG exports only compress the generated pixels: no cropping, resampling, compositing, painted labels, or added promotional typography. Per-image export settings, source paths, visual QA, and SHA-256 hashes are recorded in `provenance/`. Earlier attempts, if retained, are not shipped.

- `originals/`: original generated PNG files
- `final-web/`: superseded still-life JPEG exports
- `prompts/`: exact generation/edit prompts
- `provenance/`: source references, export records, visual QA and hashes

Product names, approved scent statements, and buttons are live Liquid text using the supplied Cenzo Flare Bold and Helvetica Now Display Light fonts. Product-label lettering remains part of the photograph. One banner image serves both Light and Dark; a native CSS overlay protects desktop copy contrast, while mobile places the title below the photograph. Full names are not repeated as headings in the detail panel.

These files are separate from the locked twelve-frame product galleries. No previous gallery or general campaign image was changed. No Shopify Admin edits were performed for this revision.
