# Export notes

All photographic sources were newly generated for this request using the built-in ImageGen tool. No legacy gallery images were reused. Native ImageGen returned 1254×1254 despite the 2048 request and exposes no size argument; original native sources are preserved in `working/`. Final photography is transparently resampled with Lanczos to the required 2048×2048 sRGB PNG. All deterministic type is rendered directly at 2048×2048.

The 2026-09-24 typography refresh uses the actual user-supplied Cenzo Flare Bold TTF for promotional headings and Helvetica Now Text Regular TTF for body copy. The user explicitly supplied Text Regular in place of the earlier Display specification. These are embedded raster text from the supplied binaries, with no system-font substitution. Physical bottle/canister label typography is unchanged. Earlier system-font versions are safely archived under `archive/2026-09-24-system-font-version/`.

Only frames 04/08/09/10/11/12 were re-rendered from clean source photos and deterministic layout code. All photos and verified copy are preserved; no image patching or ImageGen edit was required because the promotional captions were separate deterministic overlays. Optimized website derivatives are 1200×1200 progressive JPEG quality 88.
