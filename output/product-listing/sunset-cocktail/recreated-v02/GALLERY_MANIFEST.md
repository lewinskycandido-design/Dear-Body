# Sunset Cocktail Recreated Gallery v02

Status: Final 10-image Shopify gallery.

## Production Method

- Built-in image generation created the clean studio, editorial, lifestyle, and rooftop environments.
- The supplied clean front-bottle master was isolated and composited into every bottle scene for consistent packaging geometry and label fidelity.
- Canister and cap details were isolated from the supplied product photography.
- Layout, typography, verified copy, scaling, shadows, and export were completed deterministically in the local renderer.
- The publication image was used only as a loose reference for saturated color, youthful styling, and product-forward framing.

## Export Checks

- Canvas: 2048 x 2048 px for every image
- Color profile: sRGB IEC61966-2.1
- Formats: JPG for photographic scenes, PNG for text-heavy product information
- Maximum file size: below Shopify's 20 MB image limit
- Model rule: male-presenting models only for this black-label men's product
- Claims rule: no unverified concentration, fragrance notes, performance, or usage claims
