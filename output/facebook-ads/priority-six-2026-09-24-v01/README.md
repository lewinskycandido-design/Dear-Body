## Copy and visual system

Every ad begins with FREE SHIPPING / ON 2+ ITEMS, followed by CASH ON DELIVERY, and ends with the exact scent name and SHOP NOW. The threshold and payment offer come from the current user request. No price, discount, shipping coverage, deadline, or performance claim has been added.

Photographic bases were generated with the built-in ImageGen tool using the approved product image for each scent. Headlines, scent names, and CTA use the actual supplied Cenzo Flare Bold font. Supporting copy uses the supplied Helvetica Now Display Light. Official Dear Body logo artwork is used. Scent-colored panels, cream, burgundy, and curved graphic accents create a coordinated campaign. Photographic scenes are AI-generated, styled to resemble a commercial lifestyle shoot.
